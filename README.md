# Data

The original project used MTN Ghana historical trading data.

The working project contained:

- `MTN.xlsx` — 1,904 observations × 13 original variables
- `MTN_Clean.csv` — 1,901 observations × 11 variables
- `Final_Dataset.csv` — 1,740 observations × 47 variables after feature engineering

The data span **5 September 2018 to 29 May 2026** in the original workbook.

## Why the data files are not included here

The redistribution/licensing status of the source dataset has not been established for public GitHub distribution. To avoid publishing data without permission, the raw and processed datasets are intentionally excluded from this repository.

To reproduce the notebooks, place the required files in this directory using the names expected by the notebooks/configuration.

> **Important:** The academic report associated with the project states a broader period beginning in 2010. The actual dataset supplied with the project begins on 5 September 2018. The repository therefore documents the date range of the supplied data rather than repeating the inconsistent report statement.
